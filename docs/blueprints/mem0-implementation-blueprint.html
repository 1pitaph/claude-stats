07 Claude Stats 接入逻辑 SIDECAR INTEGRATION
01. 固定本地存储
Mem0Adapter 初始化时指定 Qdrant path 为 config.qdrant_path，collection 为 claude_stats_memories，history DB 为同目录 mem0-history.sqlite3。
02. 模型配置
LLM provider 根据协议选择：OpenAI chat completions、OpenAI Responses 自定义 provider、Anthropic Messages 自定义 provider；embedding 固定使用 OpenAIEmbedding 兼容接口。
03. source capture
每个 chunk 组装 metadata、run_id、source refs、scopes，再调用 client.add(... infer=True)，让 mem0 管理提取。
04. manual memory
capture_memory、index_memory 使用 infer=false，把 canonical memory 原文直接存入 mem0。
05. mirror conversion
mirror_from_mem0_item 将 mem0 item 转成 sidecar memory，保留 provider_id、mem0_id、source_refs、scopes 与 status/type/title。
06. search surface
sidecar 搜索固定 filters 为 {"user_id": project_id, "status": "active"}，返回 rank、score、memory、match_kind=mem0。
